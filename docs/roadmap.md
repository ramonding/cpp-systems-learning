# 长期学习路线

职业方向：C++ / Linux Systems & Infrastructure。Storage 为主，Robotics Infrastructure 为后续探索方向。

| 阶段 | 内容 |
|---|---|
| C++ 基础 | 内存、对象生命周期、RAII、智能指针、move、STL、模板 |
| C++ 并发 | thread、mutex、condition_variable、atomic、内存模型 |
| OS / Linux | 进程线程、虚拟内存、调度、文件与 IO、fd、mmap、signal、epoll、IPC |
| Network | TCP/IP、Socket、重传、流控、诊断 |
| 数据结构与算法 | Hash、Tree、Heap、搜索、排序、常见算法 |
| Filesystem / Storage | VFS、inode、page cache、SMB/NFS、Snapshot、一致性 |
| 性能与可靠性 | 并发 IO、性能分析、State Machine、Retry、Timeout、幂等、恢复 |
| System Design | 大规模文件扫描、数据系统与设计取舍 |
| 后续探索 | ROS2、DDS、Robot Runtime、Data Pipeline |

近期考试冲刺优先。考试后按实际完成情况继续，不依据经过的周数认定已掌握。
