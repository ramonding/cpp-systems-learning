# 科目一与科目四：五周冲刺

制定日期：2026-10-07。规划截止日暂为2026-11-15，实际考试日期确定后调整。

| 日期 | 编程 | 设计与重构 |
|---|---|---|
| 10/07～10/11 | 环境验证、算法与状态管理诊断 | 设计场景、坏味道诊断 |
| 10/12～10/18 | 字符串、模拟、排序、Hash | 职责、耦合、Factory、Strategy |
| 10/19～10/25 | 窗口、二分、区间、栈 | Observer、Adapter、Decorator |
| 10/26～11/01 | DFS/BFS、多操作状态管理 | State、Command、渐进重构 |
| 11/02～11/08 | Heap、基础DP、混合模拟、补缺 | 模式辨析、需求变化与重构步骤 |
| 11/09～考试前 | 限时模拟与错题独立重写 | 场景与代码辨析模拟 |

每周6.5小时：科一4小时、科四2.5小时。科一约20～28道不同练习，加8～12次复做；科四每周4～6个场景/代码辨析练习与一个小重构例子，根据实际能力调整。

## 验收

- 编程：独立完成、真实编译运行、检查边界、解释正确性和复杂度。
- 设计：说明变化点、选择理由、替代方案与代价；重构用测试验证行为保持。
- 一次一题，先思考再提示；模拟结束后再讲评。
