2026 年 11 月中旬：准备 C++ 专业级考试的科目一与科目四。具体考试规则以本人参加的考试说明为准；本仓库的题目和验收标准均为学习训练安排。

默认每周 6.5 小时：上机编程 4 小时，设计与重构 2.5 小时。

## 学习方式

学 → 写 → 联 → 讲：先分析，独立实现，编译运行，Review，复做，再解释原理。

题目用了提示就记录“辅助完成”；能够独立重写和解释后再标记掌握。日志区分计划、进行中和已验证，不把列出的任务当成已完成。

每周记录：完成内容、代码与运行证据、错因、复做安排、下周调整。
